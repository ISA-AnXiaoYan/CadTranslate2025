# Implementation experience

1. **Freeze originals before any CAD session.** Core Console can change its active `/i` drawing during open/exit. Make a byte-verified staging copy; keep a second frozen input for scan and apply. Verify original hashes at delivery.
2. **Separate CAD work from network work.** Scanning and writeback belong on the AutoCAD command thread. Pure .NET translation workers may run concurrently. Synchronous waiting on async work on the CAD command thread can hang small-file processing.
3. **Freeze terminology before translating.** Cross-file independent caches produced inconsistent terms. Use a project-wide canonical source-to-target map keyed by language, professional context and glossary version. Scope uncertain interpretations to file/handle/context and preserve the original wording with the proposed Chinese meaning.
4. **Check native entities, not process success.** Protected-token checks, handle/current-source validation, write-error counts and saved-file readback are distinct checks. A numeric `confidence` response must not crash an optional metadata parser.
5. **Locked layers remain in translation scope.** Temporarily unlock layers in the output database and restore lock flags before committing. Do not count caught `eOnLockedLayer` exceptions as successful translation.
6. **Bind a real Chinese font descriptor.** A font file path alone left an empty typeface in our test. Assign `FontDescriptor("Microsoft YaHei", false, false, 134, 34)` last; saved metadata may return the localized name `微软雅黑`. Bind translated entities to the new style and clear conflicting MText font overrides. Reopen and verify the descriptor and entity style IDs.
7. **OLE has two contents to update.** Translate string cells in the displayed worksheet, preserve formulas/numeric inputs, and refresh the presentation cache. Updating only the embedded XLSX does not guarantee Chinese is visible in DWG.
8. **Use native OLE writeback with validation.** In the tested headless engine, DXF import dropped OLE storage, even for unmodified payloads. CopyFiler serialization preserved storage, object handles and placement. FileFiler mode crashed the disposable test process and must not be used.
9. **Preserve Office calculations and layout.** Translate text only, keep cell addresses, merges, formatting and formulas, set Chinese fonts on changed cells, recalculate once, compare formula strings and numeric values, then render the updated cached presentation.
10. **Constrain background process ownership.** Use `CreateNoWindow`, hidden process style, redirected Unicode logs, explicit process IDs and bounded deadlines. Stop the scheduler before stopping its children, otherwise it may dispatch further jobs.

Validation established engineering coverage in specific local samples, not universal DWG compatibility. Embedded OLE editing and native serialization need file-specific qualification. Keep original/customer evidence private and outside this repository.
