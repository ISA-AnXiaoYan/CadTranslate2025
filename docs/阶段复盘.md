# DWG 翻译阶段复盘

本阶段把首轮批量翻译、逐图复核、PDF 转图补译和增补单图串成可复用流程。公开入口可分步运行，复核人员可在写回前检查术语、内容范围和待核项。[后台操作手册](HEADLESS.md)

| 阶段 | 已完成的验证 | 对流程的改进 |
| --- | --- | --- |
| 批次复核 | 复核原 19 张 DWG，修正 803 处原生文字。补查 607 个块内容引线，核对 2,428 条属性值。 | 以图元句柄、原文和对象类型定位问题。房间名称进入翻译，回路号、线缆规格等按语境保留。 |
| PDF 转图 | 追加 3 张图，处理 8,263 处文字，随成果交付 143 个图像资源。22 张原始 DWG 和 22 张成果都完成哈希核验。 | 用同图层及邻近关系恢复拆开的复合术语。使用相对图片引用，并按原目录结构交付资源。 |
| 内嵌工作簿 | 核查 19 个 OLE 对象，每个对象含 34 张工作表。共执行 42,710 次单元格文字修改，计入重复嵌入副本。 | 按工作表与地址匹配源值。对全部工作表检查公式、数值、合并范围和译文字体，并刷新图面显示缓存。 |
| 增补单图 | 完成另一张污废水图的 329 处修改，其中 34 处为 CAD 表格单元格。原件哈希核验通过。 | 区分原生 CAD 表格与 OLE。使用图元句柄加行列坐标写回，保留公式、字段及图例块内容。 |

术语复核的关键产物是带来源和范围的执行表。经过批准的精确别名优先于旧缓存。PDF 导入的拆词适合用位置证据确认，例如将相邻的设备名片段统一为“电外科设备”或“麻醉机”。原文功能不清时保留原词、候选释义和待核标记。

保存后检查要覆盖显示和存储两个层面。DWG 文本正确仍需检查字体绑定。OLE 包内译文正确仍需刷新显示缓存。表格翻译还要核对行列位置、合并范围和公式结果。原图已有的面积占位及原表既有列宽问题属于输入问题，复核报告应记录原始状态。

公共仓库提供分阶段工具、通用术语结构和操作示例。项目图纸、具体术语和运行证据保存在私有任务目录。公开代码的独立实测包括原生表格、相对目录交付、显示与非显示工作表回写、缓存渲染和编号保护。代理实体、矢量轮廓文字、图像 OCR 及自动排版仍需独立处理。[公开版验证范围](HEADLESS.md#验证范围)
